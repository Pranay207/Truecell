# Build verification — Truecell 2.0 working source

Core QA was rerun locally on Windows with 64-bit Python 3.11.9 on 22 October 2026. The project declares version constraints for its application and development dependencies; the Python distribution, package index, container base image and operating-system packages remain upstream build inputs. These are development checks, not hidden-document accuracy claims.

- **304 Python tests passed** in the final source tree. Ruff lint and formatting checks passed, `pip check` found no broken requirements, and strict recorded-output verification passed all 23 workbooks against their frozen audits at cell, data-type and number-format level.
- **16 frontend tests passed**, followed by strict TypeScript checks and an optimized Vite production build. The checked-in `frontend/dist` matches that build. Coverage includes extracted-row search, original-index preservation, OCR-language upload options, snapshot-safe review requests and recovery behavior.
- **23/23 source-bound dummy development cases passed** exact truth checks. All 46 audit/XLSX artifacts were regenerated in one run from the audited tree; the suite includes the raster-only five-page continuation, disclosed 13-page equivalent, 18-column borderless table, explicitly ruled vertical spans, sideways scan, no-table control and 50-page/800-row stress fixture. See `ACCURACY_REPORT.md` for exact results and measured timings.
- **5/5 engine-isolated scan cases passed** with external Tesseract excluded: inventory, blur/noise, skew, perspective photo and sideways invoice. This exercises bundled RapidOCR and is not an unseen-document or cross-platform accuracy claim. See `PORTABLE_OCR.json`.
- **Windows x64 portable passed its full smoke test** from a path containing spaces: health/UI, exact native extraction, bundled RapidOCR scan, Excel/audit downloads and workspace persistence after restart. The rebuilt folder is **316.71 MiB** and ZIP is **152.53 MiB**; ZIP SHA-256 is `e786bec9bb3fa46d316c964552c82b47f56cf999af38800ae9bb4f65df50b3ea`. The generated ZIP remains Git-ignored.
- **Docker verification passed**: Compose configuration, clean final image build, non-root UID 100, healthy status, English/Hindi/Telugu Tesseract packs plus RapidOCR, exact native and scanned OCR extraction, React UI, Excel/CSV/audit downloads and workspace restoration after container restart. The temporary test volume was removed afterward. The local intercepting proxy required the scoped `PIP_TRUSTED_HOST` build argument for the two official PyPI hosts.
- The cached public audit passed its disclosed scope: 35/35 fuel-table cells and seven headers; 48/48 selected census cells, all 16 headers and both table shapes; zero invented tables for the W3C control; and 126/126 cells plus 14/14 flattened headers across two public Unicode tables. The other 464 census data cells were not independently checked. These are known development inputs, not blind evaluation.
- FastAPI tests cover upload, source inspection, edits, immutable baselines, complete paginated review, per-item acknowledgements, honest partial/failed/quality states, Draft versus Reviewed Excel gates, CSV/audit downloads, workspace deletion and reprocessing boundaries. Frontend unit tests cover API requests and display formatting. The packaged server served the rebuilt React UI, but browser surfaces were unavailable for a new live screenshot pass in this automation session; native Excel rendering was also not performed.
- The offline environment check succeeded and verified the bundled English model checksum. No API credentials or live vision-provider calls were used. Python 3.10/3.12 and Linux/macOS are supported targets with CI configuration, not locally executed platform results.

The upgrade adds per-page quality/content/script profiling, damaged-text OCR escalation, optional multilingual Tesseract routing, evidence-ranked cross-checks, semantic column roles, repeated-header consensus, full-width-title separation, stronger structural validation, complete evidence accounting, a paginated exception queue, honest result states, quality-gated Reviewed Excel, CSV delivery, Docker Compose and a two-stage blind-evaluation harness. Regression checks include a disclosed 13-page/four-table equivalent and keep every repair or human edit explicit. Heuristics still require source review.

Known limitations include handwriting, uninstalled OCR language packs, broken glyph maps, severe cropping and imperfect OCR descriptions on some external scans. Source-backed merged headers and explicitly ruled vertical or horizontal spans are supported conservatively for native and OCR tables; ambiguous unruled inheritance and irregular multi-axis nested layouts remain review cases. Mathematical agreement and recognition confidence are not correctness guarantees. Human edits and proposals remain explicit; the benchmark never auto-applies arithmetic repairs. The default server binds to loopback. Optional `--lan` access is limited to the detected RFC 1918 host and private-network clients, can depend on the computer's firewall setting, adds no authentication and must be used only on a trusted private network.

The current source tree contains the launchers, engine, bundled frontend, OCR model, 23 dummy input/truth/output sets, reports, tests, portable build instructions and licence notices. Generated environments, dependency caches, temporary files, runtime workspaces, local build folders, credentials and personal data remain ignored. The portable ZIP is a local release artifact and is not committed to Git.

`docker compose config`, the image build, native/OCR server smoke checks and persistence verification after restart all passed on the audited tree. GitHub Actions repeats the quality, 3-OS/3-Python, frontend and Docker gates after push.

External application implementations and comparative review materials remain outside this project. `analysis/` and temporary review directories are absent. The final 3:53 demo is included under `docs/demo/`, with its recording script in `docs/DEMO_SCRIPT.md`, and is publicly viewable at https://pranay207.github.io/Truecell/demo/. The organizer's real submission destination is not stored in this repository.
