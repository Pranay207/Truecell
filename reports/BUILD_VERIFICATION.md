- Streamlit AppTest still covers the fallback interface, including initial/result rendering, ragged rows, duplicate labels, stale inspector coordinates and finding-to-source navigation. - The offline environment check succeeded and verified the bundled English model checksum. No API credentials or live vision-provider calls were used. Python 3.10/3.12 and Linux/macOS are supported targets with CI configuration, not locally executed platform results.

The upgrade adds a responsive React/TypeScript workspace, a loopback-only FastAPI adapter, source-to-cell inspection, counterfactual validation previews, a bounded validation challenge, resumable extraction and safe workspace forking. The extraction engine also adds font/geometry-backed native headers, OCR headers supported by numeric records, alternating-empty-column preservation, conservative wrapped-cell reconstruction, retained page summaries, unruled totals with source evidence, orientation retries and optional independent rotated readings. Regression checks caught and corrected numeric-only row loss, numeric bold rows mistaken for headers, false dark-header separators, shallow footer-crop failures and incorrect orientation ranking. Heuristics still require source review.

Known limitations include damaged text layers, handwriting, all-text borderless tables without clear header styling and imperfect OCR descriptions on some external scans. Explicitly ruled vertical group spans in native-PDF body rows are supported conservatively; OCR/unruled spans and arbitrary multi-axis nested merges remain ambiguous. Mathematical agreement and recognition confidence are not correctness guarantees. Human edits and proposals remain explicit; the benchmark never auto-applies arithmetic repairs. The default server binds to loopback. Optional `--lan` access is limited to the detected RFC 1918 host and private-network clients, remains available only while the server runs, and can still depend on the computer's private-network firewall setting.
