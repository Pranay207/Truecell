TRUECELL — DOCUMENT INTELLIGENCE

1. Easiest on Windows 10/11 x64: extract Truecell-Portable-Windows-x64.zip,
   keep the complete folder together, and double-click Truecell.exe.
   Python, Node.js, an API key and internet are not required.
2. Source fallback: double-click START_TRUECELL.cmd on Windows or run
   bash start.sh on Linux/macOS. This first setup needs internet and
   64-bit Python 3.10–3.12; later source launches work offline.
3. Open the localhost URL printed by the launcher.
   Optional phone demo: START_TRUECELL.cmd --offline --lan, then open the
   printed Phone URL from the same trusted private Wi-Fi network. LAN mode has
   no authentication; never expose it to the public internet.
4. Click “Find a wrong balance”, then open “Review” in the validation rail.
   The priority queue opens each uncertain or invalid value at its source.
   Mark an item checked only after inspecting that evidence. Then open “Equations”.
   Inspect printed 1081.00 and the 1064.00 proposal supported by two
   adjacent balance equations. Preview without changing the working data.
5. Select the finding to inspect its source and preview the proposal impact.
   Open the invoice sample to show its page-join receipt. Draft Excel and CSV
   remain available for working data; Reviewed Excel unlocks only after every
   current priority item has been individually checked against its source.

Quick-demo buttons: Invoice register / Find a wrong balance / Skewed scan.
Upload Sparse text schedule / Sideways invoice / Page carry-forwards from
the samples/ folder. All sample data is dummy.
All 23 dummy PDFs, truth workbooks and converted workbooks are in the source folder.
The 13-page equivalent sample is a disclosed synthetic development fixture, not
blind evidence. External evaluators can use docs/BLIND_EVALUATION.md for a
truth-withheld run on unseen authorized documents.

CLI: python convert.py samples/A_invoice_register.pdf -o outputs/demo.xlsx
Multilingual CLI: python convert.py input.pdf -o output.xlsx --ocr-languages eng+tel+hin
Docker: docker compose up --build
Tests: python -m pytest -q
Fast recorded-output verification: python scripts/verify_recorded_outputs.py
Full development evaluation: python scripts/judge_check.py
