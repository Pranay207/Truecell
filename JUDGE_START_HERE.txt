TRUECELL — DOCUMENT INTELLIGENCE

1. Use 64-bit Python 3.10–3.12. Python 3.11 on Windows was tested locally.
2. Windows: double-click START_TRUECELL.cmd. Linux/macOS: bash start.sh.
   First setup needs internet; normal conversion is offline on CPU.
3. Open the localhost URL printed by the launcher.
   Optional phone demo: START_TRUECELL.cmd --offline --lan, then open the
   printed Phone URL from the same private Wi-Fi network.
4. Click “Find a wrong balance”, then open “Review” in the validation rail.
   The priority queue opens each uncertain or invalid value at its source.
   Mark an item checked only after inspecting that evidence. Then open “Equations”.
   Inspect printed 1081.00 and the 1064.00 proposal supported by two
   adjacent balance equations. Preview without changing the working data.
5. Select the finding to inspect its source and preview the proposal impact.
   Open the invoice sample to show its page-join receipt, then Export Excel.
   The workbook includes Join Receipt and Cell Evidence sheets.

Quick-demo buttons: Invoice register / Find a wrong balance / Skewed scan.
Upload Sparse text schedule / Sideways invoice / Page carry-forwards from
the samples/ folder. All sample data is dummy.
All 22 dummy PDFs, truth workbooks and converted workbooks are in the source folder.
The existing submission ZIP predates the latest upgrades; rebuild only when ready.
